Рабочая программа

Для кого. Студенты педагогических направлений и преподаватели с базовым знакомством с Python.

Цель. Научиться преобразовывать текстовый список в готовый комплект билетов для экзамена.

Учебный план. Три занятия по одному академическому часу и один академический час на итоговую работу.

Что понадобится. Python 3, текстовый редактор, библиотека python-docx и программа для открытия файлов Word.

Проверка результата. Готовый документ содержит 24 пронумерованных билета по три разных вопроса в каждом. Один вопрос может встречаться в разных билетах.

Уроки

1. Список вопросов

Подготовьте исходный файл.

2. Выбор вопросов

Сформируйте билеты с помощью Python.

3. Документ Word

Запустите генератор и проверьте результат.

Итоговая работа

  1. Скачайте скрипт и образец. Сохраните их в одной папке.
  2. Замените вопросы в voprosy.txt на 10–15 своих вопросов по учебному предмету.
  3. Откройте терминал в этой папке и выполните команды.
python -m pip install python-docx
python generator.py

Если команда python не найдена, попробуйте py на Windows или python3 на macOS и Linux.

Откройте bilety.docx. Проверьте количество билетов и убедитесь, что внутри каждого три разных вопроса. Для проверки работы сдайте список вопросов и готовый документ.
